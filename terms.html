MT Research Uploader · last updated 9 November 2026

MT Research Uploader ("the tool") is an internal command-line tool operated by MT Research. It uploads MT Research's own short videos to MT Research's own YouTube channel, @mtresearchxyz. It is not offered, sold or distributed to anyone else.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy, and how the tool handles data is described in our Privacy Policy.

Who may use it

Only the owner of the MT Research channel signs in. The tool refuses a sign-in for any other YouTube channel.

What it does

It uploads a finished video, sets its title, description and thumbnail, and posts one comment under it, on the MT Research channel only. It does not read, change or delete anything else.

Ending access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer removes all data the tool stores.
